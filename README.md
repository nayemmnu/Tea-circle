# ☕ Tea Circles

Create circles of close friends, set a message for each circle
("Come for tea ☕", "Let's go out 🚶"), and **tap the circle once** to notify
everyone. Live board: 🟢 coming · 🔴 can't · ⚪ offline/unavailable · 🟡 waiting.

Flutter (Android) + Firebase (Auth, Firestore, Cloud Messaging, Cloud Functions).
The `android/` folder is **generated by GitHub Actions**, so you never need
Android Studio.

---------------------------------------------------------------------------

## 1. Firebase setup (once, ~15 min)

1. https://console.firebase.google.com → **Add project**.
2. **Add app → Android**. Package name must be exactly:

       com.teabreak.circles

   Download **google-services.json** and put it in the **repo root**
   (next to `pubspec.yaml`). Commit it. (Keep the GitHub repo *private*.)
3. **Build → Authentication → Sign-in method → Email/Password → Enable.**
4. **Build → Firestore Database → Create database.**
   Choose location **asia-south1 (Mumbai)** (closest to Bangladesh), then
   start in production mode.
   > If you pick another location, edit `REGION` at the top of
   > `functions/index.js` to match.
5. Upgrade the project to the **Blaze** plan (Cloud Functions require it;
   for a group of friends the bill is effectively $0, and you can set a
   budget alert).
6. Deploy rules, indexes and the function from your computer:

       npm install -g firebase-tools
       firebase login
       firebase use --add          # pick your project
       cd functions && npm install && cd ..
       firebase deploy --only firestore,functions

   (The index takes a few minutes to build. Until then the "incoming calls"
   card on the home screen shows an error.)

## 2. Build the APK on GitHub

1. Create a **private** GitHub repo and push this whole folder.
2. Open the repo → **Actions → Build APK → Run workflow**
   (it also runs on every push to `main`).
3. When it turns green, open the run → **Artifacts → tea-break-circles-apk**
   → download, unzip, and install `app-release.apk` on your phone
   (allow "install unknown apps").
4. Send the same APK to your friends.

If the build fails, open the failed step and send me the last ~30 lines of
the log.

## 3. Using it

1. Everybody installs the APK, **creates an account** (name, email, password)
   and allows notifications.
2. Create a circle → give it a name and a message → add friends **by the
   email they registered with**.
3. Tap the circle. After a 4-second UNDO bar the call is sent and you see
   the live board.
4. Friends get a notification with **✅ I'm coming / ❌ Can't** buttons
   (also shown as a card inside the app).

## How "offline = unavailable" works

* The server sends a push to each friend.
* When a phone receives it, the app immediately writes `delivered` back.
* If nothing comes back within 45 s the friend turns grey (unavailable).
  The push also expires after 60 s, so an offline phone never gets a
  stale "come for tea" hours later.

## Good to know

* **Xiaomi / Oppo / Vivo / Realme / Samsung**: tell friends to set the app's
  battery mode to *Unrestricted / No restrictions* and enable *Autostart*,
  otherwise the phone may kill the app and never receive the push.
* Any member can tap a circle; only the creator can edit or delete it.
* Anyone signed in can look up an account by email (needed to add friends).
* Installing a new APK over an old one works because the build uses a fixed
  signing key (`tools/debug.keystore`). That key is for personal sideloading
  only; do not publish this APK to the Play Store as is.

## Project layout

    lib/main.dart                     app entry + login gate
    lib/models.dart                   data classes + status colours
    lib/services/circle_service.dart  Firestore reads/writes
    lib/services/notification_service.dart  push + ✅/❌ buttons + delivery ack
    lib/screens/                      login, home, circle editor, live board
    lib/widgets/invite_card.dart      in-app incoming call card
    functions/index.js                sends pushes, marks offline people
    firestore.rules / firestore.indexes.json
    .github/workflows/build-apk.yml   builds the APK
    tools/patch_android.py            wires Firebase into the generated android/
