# ☕ Tea Circles (free Spark plan, no card needed)

Create circles of close friends, set a message for each circle
("Come for tea ☕", "Let's go out 🚶"), and **tap the circle once** to notify
everyone. Live board: 🟢 coming · 🔴 can't · ⚪ offline/unavailable · 🟡 waiting.

Flutter (Android) + Firebase **Spark (free)**: Auth, Firestore, Cloud Messaging.
No Cloud Functions: the phone that taps the circle sends the notifications.
The `android/` folder is generated by GitHub Actions.

---------------------------------------------------------------------------

## Setup checklist

### A. Firebase console (https://console.firebase.google.com)
1. Project → add **Android app** with package name `com.teabreak.circles`,
   download **google-services.json**, put it in the repo root, commit it.
2. **Security → Authentication → Get started → Email/Password → Enable.**
3. **Databases & Storage → Firestore → Create database** (Standard,
   production mode, any location).
4. Deploy the security rules and index (works on the free plan):

       npm install -g firebase-tools
       firebase login
       firebase use --add
       firebase deploy --only firestore

### B. Push key (Google Cloud console, free)
The app needs a small "key" that is allowed to do ONE thing: send
notifications.

1. https://console.cloud.google.com/iam-admin/serviceaccounts
   (choose your Firebase project in the top bar).
2. **Create service account** → name `push-sender` → **Create and continue**.
3. Role: search **Firebase Cloud Messaging API Admin** → select it →
   **Continue → Done**.
4. Click the new account → **Keys → Add key → Create new key → JSON → Create**.
   A `.json` file downloads.
5. GitHub repo → **Settings → Secrets and variables → Actions →
   New repository secret**. Name: `FCM_SERVICE_ACCOUNT`.
   Value: open the downloaded file in Notepad, copy EVERYTHING, paste.
6. Delete the downloaded file from your computer. **Never commit it.**

### C. Build
Push to GitHub (Actions → Build APK builds it) and download the APK from the
run's Artifacts. Re-run the workflow after adding the secret.

## How "offline = unavailable" works

* Your phone sends a push to each friend (time-to-live 60 s).
* When a friend's phone receives it, the app instantly writes `delivered`.
* If a friend's phone has not confirmed within 45 s, the board shows them
  grey (unavailable). If they come online later and answer, it turns green/red.

## Good to know

* The push key is inside the APK. It is restricted to sending notifications,
  but **only share the APK with people you trust**. If it ever leaks, delete
  the key in Google Cloud (service account → Keys) and create a new one.
* Your phone must be online to send the call. If it isn't, the board shows
  "Sending…" and the friends are told once you reconnect (their in-app card
  appears; the push may not, because pushes are only valid for 60 s).
* Xiaomi / Oppo / Vivo / Realme / Samsung: set the app's battery mode to
  *Unrestricted* and enable *Autostart*, or the phone may never get the push.
* Any member can tap a circle; only the creator edits or deletes it.
* Fixed signing key (`tools/debug.keystore`) lets new APKs install over old
  ones. For personal sideloading only.
